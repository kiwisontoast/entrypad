Entrypad
Editor For developers GitHub

What if accounting visuals moved the way the books do?

Entrypad draws T-accounts, the accounting equation and the financial statements from your journal entries. Drag a transaction onto the books and every view updates with it.

How it works

  1. Write the entries

    Write the general journal the way you already do: date and memo, debits flush left, credits indented. Paste rows from a spreadsheet or open an hledger journal if you have one. 

    
          
    2. 
          
  2. 
            
    See the books
    
            
    Entrypad works out the T-accounts, the equation and the statements from those lines, to the cent.
    
            
    
          
    3. 
          
  3. 
            
    Drag to change them
    
            
    
              Drag an amount up or down to change it, or onto another account to reclassify it. The text and every other
              view follow.
            
    
            
    
          
    4. 
        

      


      

        
The visuals

        
One journal drives all of them, so they always agree. Each one works in place; open any in the editor to change the book.

        

      


      

        
Try it

        

          Edit the entries and watch the books change. Mistakes don't stop anything: the full editor underlines them as
          you type.
        

        

      


      

        
For developers

        
Entrypad is a TypeScript library for React. Install it from npm:

        
npm install entrypad

        
Then give any visual a book:

        

        

          Every visual exports to SVG, PNG and GIF, and @entrypad/markdown draws entrypad code
          blocks in docs sites and Markdown slide decks.
